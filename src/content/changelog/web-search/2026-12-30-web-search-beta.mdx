Cloudflare Web Search is now available in beta. Web Search is a search API that gives your agents and applications real-time access to the public web.

Send a query, get back a list of URLs with titles, descriptions, and metadata. Pair it with [Browser Run](/browser-run/) to fetch full page content, extract structured data, or generate screenshots from any result.

With Web Search you can:

- **Ground LLM responses** with current search results before generating a response
- **Build research agents** that search across queries and synthesize content from multiple sources
- **Add web search to MCP clients** like Claude Code, Cursor, OpenCode, or any MCP client
- **Search from anywhere** using a [Workers Binding](/web-search/get-started/#workers-binding), the [REST API](/web-search/get-started/#rest-api), or the [Agents SDK](/web-search/ai-integration/agents-sdk/)

For example, to search for a query using the REST API:

```bash
curl -X POST \
  https://api.cloudflare.com/client/v4/accounts/{account_id}/websearch/search \
  -H "Authorization: Bearer {API_TOKEN}" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "latest Cloudflare announcements",
    "limit": 5
  }'
```

Or using a Workers Binding:

```ts
const { items } = await env.WEBSEARCH.search({
	query: "latest Cloudflare announcements",
	limit: 5,
});
```
