Web Search is billed per query. Each call to `search()` or the REST API counts as one query.

| Plan               | Workers Free    | Workers Paid            |
| ------------------ | --------------- | ----------------------- |
| Included queries   | 1,000 per month | 3,000 per month         |
| Additional queries | Not available   | $5.00 per 1,000 queries |

Included queries reset at the start of each monthly billing cycle. On the Workers Free plan, queries beyond the included amount are rejected until the next billing period. On the Workers Paid plan, additional queries are billed at the overage rate.

To view or change your plan, go to the **Workers plans** page in the Cloudflare dashboard:
