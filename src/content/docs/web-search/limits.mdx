## Account limits

| Limit | Workers Free | Workers Paid |
| --- | --- | --- |
| Included queries per month | 1,000 | 3,000 (then billed) |

## Request limits

| Limit | Value |
| --- | --- |
| Max results per query (`limit`) | 50 |
| Default results per query | 10 |
| Min results per query | 1 |
| Max query length | 1,024 characters |

## Response fields

| Field | Type | Always present |
| --- | --- | --- |
| `url` | `string` | Yes |
| `title` | `string` | Yes |
| `description` | `string` | No |
| `summary` | `string` | No |
| `authors` | `string[]` | No |
| `imageUrl` / `image_url` | `string` | No |
| `faviconUrl` / `favicon_url` | `string` | No |
| `lastModifiedDate` / `last_modified_date` | `string` | No |

Optional fields depend on the page's metadata. Not all pages have OpenGraph images (`thumbnailUrl`) or meta descriptions (`description`).

## Beta limitations

During the beta period:

- Rate limits may be adjusted as usage patterns are understood.
- Additional query parameters (domain filtering, freshness, language) are planned for future releases.
- Response fields may be added in future versions. Fields will not be removed.
